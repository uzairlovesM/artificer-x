# Drawing Feature Matrix

The creative stack now exposes real concepts for stabilizer modes, pressure dynamics, symmetry, grid/perspective guides, clipping, alpha lock, selection modes, vector mode, onion skin and screen-tone workflows.

These are implemented as domain contracts and are intended to be backed by the existing raster/layer engine rather than decorative UI labels. The feature list is aligned with public ibisPaint documentation covering stabilizer, layer folders, clipping, alpha lock, vector layers, rulers, screen tone, text, manga frames, perspective tools, selection tools and transform workflows.
